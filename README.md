# Netherfortress - ネザー要塞座標通知

初めてネザーに入ったプレイヤーに、最寄りのネザー要塞の座標を自動通知するプラグインです。

---

## 機能

- **自動検出**: ネザーへの初回入場を自動検出
- **要塞検索**: 半径1000ブロック内の最寄りネザー要塞を検索
- **座標通知**: X/Z座標を表示、Y座標のヒント（32〜80付近）も案内
- **永続追跡**: PersistentDataContainer使用でサーバー再起動後も記憶
- **設定不要**: インストールするだけで動作

---

## 通知メッセージ
```
§6ネザー到達おめでとう！
§b最寄りのネザー要塞の座標: §fX: 150, Z: -300§bはここです。
§7(要塞はY座標32〜80付近に生成されます)
```

---

## 仕組み

1. プレイヤーがネザーに入る
2. PersistentDataContainerで初回入場かチェック
3. 初回の場合、`locateNearestStructure()`で最寄り要塞を検索
4. 座標をプレイヤーに通知
5. PDCにフラグを設定（2回目以降は通知しない）

---
